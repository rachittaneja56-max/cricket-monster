# Cricket.Monster — Responsive landing page v4

An editorial landing-page concept for Cricket.Monster, built around a **matchday interaction**, **Daily Monster**, and the **Fan Feed**.

## What changed in v4

- Removed the duplicate numbered strip below the hero and the repetitive marketing process section.
- Replaced the oversized white winner-pick pop-up with a compact, dark, stadium-integrated matchday panel.
- Improved headline hierarchy, photo breathing room, and mobile winner-pick controls.
- Reworked the Daily Monster preview to show the actual 10-question/3-minute format.
- Refined the Fan Feed sample and softened the final call to action.
- Preserved sample prediction, quiz, and conversation interactions.

## Design

- Field & Paper colors: `#14291F`, `#21654A`, `#E0F48A`, `#F7F7F2`.
- Barlow Semi Condensed for display, Source Sans 3 for body, with system fallbacks.
- Original cricket-stadium SVG fallback and optional sourced Unsplash photo, with attribution on the page.

## Run locally

Open `index.html` in a browser, or serve the root as a static site. No build tooling is required.

## Deploy

Connected Vercel static project. Push to `main` for the production deployment. The site requires no environment variables or paid dependencies.

## Important

**This is a design prototype.** Fixtures, picks, community posts, and quiz answers are demonstrative; no real user submissions, sign-in, scoring, or external cricket-data API requests are performed. Integrate the real product's API and authentication later.
